# Datheon Machine Learning & Data Science Internship

This repository contains four machine learning and data science tasks completed as part of my internship at Datheon.

The projects cover supervised classification, regression, ensemble learning, and natural language processing (NLP). Each task focuses on applying machine learning techniques to a specific dataset, including data preprocessing, exploratory analysis, model training, evaluation, and visualization.

The implementations use Python and commonly used machine learning libraries such as Scikit-Learn, Pandas, Matplotlib, and Seaborn.

## Internship Tasks

### Task 01 — Multi-Class Benchmark Classification

**Dataset:** Iris

Develop a multi-class classification pipeline using Logistic Regression and Decision Tree models. The task includes exploratory data analysis, feature scaling, an 80/20 train-test split, and evaluation using accuracy, precision, recall, F1-score, and confusion matrices.

### Task 02 — Housing Price Prediction

**Dataset:** California Housing

Implement and compare Ordinary Least Squares (OLS), Ridge, and Lasso regression models to predict housing prices. The task includes missing-value handling, feature engineering, data preprocessing, hyperparameter tuning, and regression evaluation using RMSE, MAE, and R².

### Task 03 — Customer Churn Prediction

**Dataset:** IBM Telco Customer Churn

Build machine learning models to predict customer churn using Random Forest and XGBoost. The task focuses on categorical feature encoding, class imbalance, cross-validation, ROC-AUC evaluation, confusion matrices, and feature importance analysis.

### Task 04 — NLP Sentiment Classification

**Dataset:** Customer Sentiment Reviews

Develop a sentiment classification pipeline using text preprocessing, TF-IDF feature extraction, Multinomial Naive Bayes, and Logistic Regression. The task also includes model evaluation and a function for predicting the sentiment of new text.

## Repository Structure

Each task has a separate directory containing:

- `data/` — Dataset files used for the task
- `notebooks/` — Jupyter notebooks containing the implementation
- `outputs/` — Generated evaluation plots and visualizations
- `README.md` — Task-specific documentation

The root directory contains shared project documentation and dependency configuration.

## Setup and Execution

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Create and activate a Python virtual environment.
4. Install the dependencies listed in `requirements.txt`.
5. Open the relevant Jupyter notebook.
6. Select the project Python environment as the notebook kernel.
7. Run the notebook cells in order.

Detailed setup instructions and project-specific observations will be updated as the tasks are completed.
